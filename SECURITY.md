# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Use GitHub's private vulnerability reporting option on this repository's
**Security** page when it is available. Otherwise, contact the repository owner
privately through [GitHub](https://github.com/dev-ansung) and include the
affected file or feature, steps to reproduce, and potential impact.

Please allow time for a response and avoid publicly disclosing the issue until
it has been reviewed and a resolution or coordinated disclosure plan is ready.

## Supported versions

This repository currently has no released software versions. Security reports
about the published Markdown and repository configuration are still welcome.
