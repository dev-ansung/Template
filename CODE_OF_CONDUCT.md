# Code of Conduct

We want this project to be a respectful place to learn, contribute, and
collaborate. Treat people with consideration, patience, and respect for
different backgrounds and experiences.

Examples of behavior that is not acceptable include harassment, discriminatory
language, personal attacks, deliberate intimidation, and sharing someone's
private information without permission.

These expectations apply in project spaces, including issues, pull requests,
discussions, and other forums used for project work.

Project maintainers are responsible for clarifying and enforcing these
expectations. They may remove content or restrict participation when needed to
protect the community.

To report a concern, contact the project owner privately through
[GitHub](https://github.com/dev-ansung). Include relevant links and context.
Please do not post reports containing private information in public issues.
